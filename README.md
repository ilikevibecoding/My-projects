# Owlingo Path

Owlingo Path is a self-contained Duolingo-inspired parody app built as a single static `index.html` file.
It includes imported Duolingo-hosted mascot artwork, a winding lesson map, interactive question cards,
daily quests, a leaderboard, and a reward modal.

## Parody notice

This project is a fan parody and is **not affiliated with, endorsed by, or produced by Duolingo**.

## What is included

- Duolingo-style lesson path with unlocked and completed bubbles
- Multiple choice, translation, and word-bank challenge types
- Energy, streak, gems, and XP counters
- Fake daily quests and a league leaderboard
- Reward modal and friend-bonus interaction
- Imported Duolingo-hosted art referenced directly in the page

## How to run

Open `index.html` in a browser.

If you prefer to serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
